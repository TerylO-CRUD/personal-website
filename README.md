# Personal Website

Welcome to my personal website, crafted using HTML, CSS, and a sprinkle of JavaScript! 
Here, you'll find a header showcasing my name along with a link to my GitHub, an About Me section, and a dedicated Projects area.

## Files

- `index.html`: This file lays out the structure of the page, including the header, About Me, Projects, and footer.
- `style.css`: Here’s where the magic happens; featuring a CSS grid for my projects.
- `script.js`: This script handles the dark mode toggle and adds a nice fade-in effect for the project cards.
- `images/`: A collection of pictures that enhance the Projects section.

## How to run

Simply open `index.html` in your favorite web browser—no installation needed!

## Features

- A centered header displaying my name and a link to my GitHub profile.
- An About Me section that includes a brief bio and my skills.
- A Projects section organized in a CSS grid that adapts beautifully to smaller screens:
  - JavaScript Calculator
  - Inventory Manager
- A cohesive blue and white color scheme throughout the site.
- A dark mode button that remembers your preference.
